ESP 32 WEB SERVER

Made with an ESP32-C3-DevKitM-1 using the Arduino IDE and the Adafruit NeoPixel Library

Features:
- A Webpage that you can access with your IP (directly from the ESP32)
- Displays the ESP32 uptime
- Displays free heap memory
- Displays the chip model, revision, number of cores, and the CPU frequency
- Displays WiFi signal strength (Received Signal Strength Indicator)
- Provides web buttons to control the LED on the ESP32 (on/off)

Software:
- Adafruit Neopixel Library
- Arduino IDE

Setup:
- Install the Arduino IDE and ESP32 support if you haven't already
- Install the Adafruit Neopixel library through the Arduino Library Manager
- Open the file in the Arduino IDE
- Put in your WiFi credentials where it says you need to
- Select the correct ESP32 board and COM port if you haven't already
- Upload the sketch
- Open the Serial Monitor at 115200 baud\
- Copy and paste the IP Address given into the browser
